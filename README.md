# Sudoku Solver

A Java-based Sudoku Solver that efficiently solves Sudoku puzzles using a recursive backtracking algorithm.

## 📌 About the Project

This project is designed to solve standard 9×9 Sudoku puzzles automatically.

The solver uses the **Backtracking Algorithm**, a recursive problem-solving technique that tries possible numbers and backtracks whenever a number leads to an invalid solution.

## 🚀 Features

- Solves 9×9 Sudoku puzzles
- Uses recursive backtracking
- Validates rows, columns, and 3×3 boxes
- Includes Sudoku game functionality
- Includes test cases for verifying the solver
- Displays test output for validation

## 🛠️ Technologies Used

- Java
- Recursion
- Backtracking Algorithm
- Object-Oriented Programming
